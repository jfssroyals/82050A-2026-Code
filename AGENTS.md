# Repository instructions

## PROS API reference

- When working with PROS APIs in this repository, consult the official [PROS for V5 API documentation](https://pros.cs.purdue.edu/v5/api/).
- Use API reference version **3.8 (3.8.0)**. Verify API names, signatures, and behavior against that version, and avoid relying on APIs introduced in later versions.

## LemLib documentation

- When working with LemLib in this repository, also consult the official [LemLib documentation](https://lemlib.readthedocs.io/en/stable/).
